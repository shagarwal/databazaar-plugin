# 2026-05-04 — v0.2

## What landed

- **Refusal guardrails wired** (`scripts/guardrails.py`). Pre-flight check on
  every acquire/aggregate/prepare request: PII-aggregation patterns + ToS
  denylist (LinkedIn, FB, IG, Twitter/X, Glassdoor, Zillow, WSJ, NYT, FT,
  Bloomberg). Blocks early with explanatory stderr + non-zero exit.
- **HuggingFace adapter** (`scripts/adapters/huggingface.py`). Searches
  HF Hub API (no auth), falls back to longest-token retry when the full
  phrase misses. Returns discovery row(s); actual row streaming deferred
  to v0.3 (requires `datasets` lib).
- **World Bank adapter** (`scripts/adapters/world_bank.py`). 12 hand-mapped
  indicators covering the most common patterns in databazaar's catalog
  (GDP, population, life expectancy, unemployment, inflation, literacy,
  CO2, internet users, labor force, school enrollment, health expenditure).
  Pulls full panel (all countries × all years).
- **Adapter router** (`scripts/adapters/__init__.py`). databazaar-first
  priority preserved; if confidence < 0.8, scores all adapters and routes
  to top match. Routing decision saved in result for audit.
- **`prepare` mode** (`scripts/prepare.py`). CSV/JSON/JSONL ingestion,
  type inference via sampling, null-rate stats, tier-1 PII scan with
  auto-redact (email/phone) and hard-block (SSN/API-key).
- **5 new eval cases** (06-10): WB, HF, prepare-clean, prepare-pii-block,
  prepare-pii-redact. Plus fixtures under `evals/fixtures/`.

## Lessons / decisions

- HF API search is keyword-fuzzy; long phrases miss. The longest-token
  fallback is cheap and effective. Worth surfacing in the datacard
  ("queries tried: [...]") in v0.3.
- World Bank's `/country/all/indicator/<code>?per_page=20000` returns
  full historical panels in one call. Works well for adapter-style use.
- Guardrails are best as keyword denylist for the request-text check
  and full-domain check for any URL inputs. Word-boundary regex avoids
  false positives like "linked" matching "linkedin".
- Kept the v0.1 run record in `evals/runs/` so the regression history
  is auditable.
